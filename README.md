# Render Module (Lightweight Lighting)

Модуль оптимизации рендера и освещения для Roblox. Разработан для использования в связке с лаунчером [Menu Visual & Optimization](https://github.com/a32435629-collab/menu-visual-and-optimization).

## 🚀 Что делает этот модуль?
Этот скрипт полностью переписывает стандартную систему освещения Roblox на облегченную (Fullbright), что дает огромный прирост FPS, особенно на слабых видеокартах и встроенной графике:
- **Отключает тяжелые тени** (`GlobalShadows`).
- **Уничтожает локальные источники света** (PointLight, SpotLight), которые нагружают GPU.
- **Заменяет сложные пост-эффекты** на легкую цветокоррекцию и атмосферу.
- **Упрощает материалы** (убирает блики и отражения).
- **Оптимизирует новые объекты** в реальном времени (если карта подгружается).

## 📂 Структура проекта
Проект собирается из нескольких модулей с помощью `build.bat`:
- `src/lighting.lua` — настройка света и атмосферы.
- `src/materials.lua` — оптимизация текстур и бликов.
- `src/optimizer.lua` — удаление лампочек и отлов новых объектов.
- `src/init.lua` — точка входа (запускает всё остальное).
- `dist/render.lua` — **готовый файл**, который скачивает и запускает лаунчер.

## 🛠️ Как использовать
1. Откройте лаунчер `Menu Visual & Optimization`.
2. Нажмите кнопку **«1. Restart Render»**.
3. Скрипт автоматически скачает `dist/render.lua` с этого репозитория и применит настройки.
